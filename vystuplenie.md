# Текст выступления на защите (~4 минуты)

**Мингазова Алия Маратовна. Интерактивный тренажёр «Логикум 0/1»**

## 1. Тема, аудитория, формат (~40 сек)

Здравствуйте. Я представляю интерактивный тренажёр «Логикум 0/1» по теме «Элементы математической логики». Он рассчитан на учеников 8 класса и построен на модуле 1.2 федеральной рабочей программы по информатике. На этот модуль отводится 6 учебных часов. Формат продукта — интерактивный тренажёр. Это веб-страница, которая открывается по ссылке или как один HTML-файл и работает без интернета.

## 2. Методическая основа (~1 мин 15 сек)

Я начинала с содержания, а не с инструментов. Тренажёр разделён на шесть вкладок, по одной на урок: высказывания, операции НЕ, И, ИЛИ, запись выражений и приоритет, вычисление истинности, таблицы истинности, логические элементы компьютера. Учитель может открыть нужный раздел по прямой ссылке, когда класс доходит до этой темы.

Каждый раздел устроен по одной схеме: короткое объяснение, затем разобранный пример, затем проверяемое задание. В разобранном примере ученик сначала сам предсказывает следующий шаг, а потом открывает решение. Это не пассивное чтение, а работа с собственной гипотезой.

В заданиях есть кнопки «Проверить», «Подсказка» и «Попробовать ещё раз». При ошибке тренажёр не показывает ответ, а объясняет правило, которое нужно применить, и указывает, где именно ошибка, например «строка 3, столбец A ∧ B». Ответы ученика сохраняются, и он исправляет их сам. Задание засчитывается только после полностью верного решения. Прогресс виден в счётчике «Выполнено N из 6».

Для наглядности в тренажёре есть модели, которыми можно управлять: цепь с лампочкой, где И — это последовательное соединение выключателей, а ИЛИ — параллельное; круги Эйлера, которые можно перетаскивать; дерево выражения, показывающее порядок действий; логические схемы, по проводам которых бежит сигнал. К каждому разделу можно скачать два PDF-конспекта: полный и с пропусками для самостоятельного заполнения. Перед заданиями есть вкладка «Повторение» с коротким видео и памяткой. Дополнительно есть итоговый тест и настоящие задания ОГЭ из демоверсий ФИПИ 2024–2027 годов.

## 3. Технически и инструменты ИИ (~1 мин)

Работа велась с тремя нейросетями. Сначала в ChatGPT я составила подробный промпт — техническое задание: содержание модуля по ФРП, структура разделов, требования к интерактивности и проверке. Этот промпт я передала Claude, и в среде Claude Code была создана сама платформа: код страницы на HTML, CSS и JavaScript, PDF-конспекты и проверка логики программы. Видео для повторения сделано в Gemini по материалам учебника.

Главное здесь — критическая проверка. Сначала нейросеть сама придумала задания «в формате ОГЭ». Я это заметила и заменила их официальными заданиями из документов ФИПИ. Все формулировки и обозначения я сверила с § 1.3 учебника Босовой. По итогам сверки исправила обозначение инвертора и добавила термины учебника «простое» и «сложное» высказывание. Ответы во всех заданиях вычисляет программа, а таблицы истинности я дополнительно посчитала вручную и сравнила с программой. При этой проверке нашлась опечатка в одном из тренировочных ответов ФИПИ, и я это задание не включила. В видео логические элементы нарисованы в зарубежном стиле, поэтому под ним есть примечание, как они обозначаются в учебнике.

## 4. Уровень SAMR (~30 сек)

Я отношу продукт к уровню **Modification**, модификации. Тренажёр не заменяет бумажный учебник, а перестраивает саму задачу. Ученик управляет моделью и сразу видит результат, получает разбор своей конкретной ошибки и проходит раздел столько раз, сколько нужно. На бумаге такой мгновенной индивидуальной обратной связи не получить.

## 5. Этика и доступность (~20 сек)

Тренажёр не запрашивает персональных данных: прогресс хранится только в браузере ученика. Цвет всегда дублируется текстом «Верно» или «Проверь ответ», все элементы управляются с клавиатуры. Весь контент, созданный ИИ, проверен по учебнику и официальным материалам.

## Возможные вопросы

- **Чем это лучше теста в Quizizz?** Здесь ученик получает объяснение ошибки, а не просто «неверно», и работает с моделями, которые можно двигать.
- **Где гарантия, что ИИ не ошибся?** Термины сверены с учебником, задания ОГЭ взяты из официальных документов, а ответы проверены программно и вручную.
- **Как учитель видит результаты?** Сейчас только на устройстве ученика, по счётчику «N из 6». Общий журнал результатов класса — возможное развитие продукта.
