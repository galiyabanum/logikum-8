# Логикум 0/1 — тренажёр «Элементы математической логики», 8 класс

Интерактивный тренажёр по модулю 1.2 «Элементы математической логики» федеральной рабочей программы по информатике (8 класс, 6 часов). Объяснения, термины и обозначения сверены с § 1.3 «Элементы алгебры логики» учебника Л. Л. Босовой, А. Ю. Босовой «Информатика. 8 класс».

## Как устроен тренажёр

Шесть вкладок соответствуют шести урокам модуля. В каждом разделе три шага:

1. **Короткое объяснение** и интерактивная модель.
2. **Разобранный пример**: ученик сначала предсказывает следующий шаг, потом открывает решение.
3. **Проверяемое задание** с кнопками «Проверить», «Подсказка», «Попробовать ещё раз». При ошибке тренажёр объясняет нужное правило и указывает место ошибки, а ответы ученика сохраняются. Задание засчитывается только после полностью верного решения. Счётчик показывает «Выполнено N из 6».

| Раздел | Что делает ученик | Интерактивная модель |
|---|---|---|
| 1. Логические высказывания | Определяет вид и значение предложений | Составное высказывание из частей |
| 2. Операции НЕ, И, ИЛИ | Вычисляет три коротких выражения | Лампочка с выключателями, круги Эйлера |
| 3. Запись выражений и приоритет | Выбирает запись и порядок действий | Дерево выражения |
| 4. Истинность составного высказывания | Вычисляет выражение по шагам | Два дерева: как скобки меняют результат |
| 5. Таблицы истинности | Заполняет таблицу | Строка таблицы на схеме, конструктор таблиц |
| 6. Логические элементы | Прогнозирует выход схемы | Схемы с бегущим сигналом |

Дополнительно: вкладка **«Повторение»** с видео и памяткой, **8 заданий ОГЭ** из официальных материалов ФИПИ и **итоговый тест** из 7 вопросов.

## Как проверялась точность

- Термины, определения, обозначения и приоритет операций сверены с § 1.3 учебника Босовой (с. 22–40) и с ФРП. По итогам сверки исправлены обозначение инвертора и термины «простое/сложное высказывание».
- Задания ОГЭ взяты из демонстрационных вариантов ОГЭ 2024–2027 и методических рекомендаций ФИПИ 2024. Ответы сверены с официальными ключами и с расчётом программы. Одно тренировочное задание исключено: ответ в документе ФИПИ (89) не совпадает с условием (правильно 85).
- Таблицы истинности всех выражений с двумя переменными посчитаны вручную и сверены с программой. Отдельно проверены 1 ∨ 1 = 1, приоритет, скобки и выходы логических элементов.
- В браузере проверены верный, ошибочный и пустой ответ, повторная попытка и сброс в каждом задании.
- Видео просмотрено по кадрам. В нём логические элементы нарисованы в зарубежном стиле, поэтому во вкладке «Повторение» есть примечание об обозначениях по учебнику.
